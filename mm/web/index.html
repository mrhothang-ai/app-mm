Bắt đầu

  1. Quản trị: Quản trị → thêm Line, chỉnh ngưỡng cấp (mặc định 200), Min/Max PO VLN chờ cấp; tạo tài khoản theo Mã NV + mật khẩu và vai trò.
  2. Planner: BOM & Model → Cập nhật BOM từ file; Dữ liệu PO → Nhập file Plan Master (Production Plan by Order); Line & tham số → khai Line chạy Model nào theo tuần, rải chuyền, pending.
  3. PO cũng có thể được đẩy tự động từ công cụ truyền dữ liệu (API có khóa).

Planner

  1. Kế hoạch kitting: tích chọn PO rồi chọn thao tác ở thanh dưới — Chuyển kitting (hàng loạt, chọn ngày + vị trí), Gộp (lấy PO chọn đầu tiên làm chuẩn, chỉ hiện PO cùng Model — khác Model Code vẫn gộp được; tổng SL không quá giới hạn, mặc định 2.500 ea), Bỏ KH. Mỗi thao tác có Hoàn tác khi kho chưa kitting. Vẫn kéo thả và nút ⋮ được.
  2. Số trên thẻ là thứ tự ưu tiên trong từng Model (F731·1, F731·2…). Kho làm xen kẽ theo lượt: ngày cũ còn sót trước, mỗi lượt lấy PO kế tiếp của mỗi Model (Model chạy N Line lấy N PO), Model đang thiếu tồn VLN lên trước, Model không chạy Line xếp cuối.
  3. Thanh Lọc cột ngày: lọc các cột ngày theo Model, Model Code, trạng thái kitting, tìm PO / Kit / Line; đầu cột hiện số thẻ khớp / tổng.
  4. Ô chọn nằm ở ô số thứ tự (không che số PO). Nút ☐ Tất cả ở đầu mỗi cột chọn / bỏ chọn mọi thẻ đang hiển thị sau khi lọc. Kéo 1 thẻ đang chọn = kéo cả nhóm thẻ đã chọn sang cột khác.
  5. Cột PO chưa lập tự xếp theo Plan Start (sớm nhất lên đầu); thẻ ghi giờ Start → End và thời lượng; cam = bắt đầu trong 24 giờ tới, đỏ = đã quá giờ. Chuyển kitting hàng loạt cũng xếp theo Plan Start.
  6. Line & tham số: lưới Line × 7 ngày (chọn Cả 2 ca hoặc từng ca), ⇥ để áp Model cho cả tuần, Chép tuần trước, + Line, chạm tên Line để đổi tên / xóa. Rải chuyền, pending; "Cấp khi Remain <" = rải chuyền + pending + ngưỡng.

BOM & Model — Planner

  1. BOM gốc theo Model Code: chọn Model (danh sách sắp theo Model, có ô tìm) → chọn Model Code → + Dòng, ⋮ để sửa / xóa (một code hoặc mọi code của Model), đổi nhóm VLN / VLĐT / Rear ngay trên dòng.
  2. BOM VLN theo Model: app tự tách từ các mã nhóm VLN, Point = Point phổ biến nhất; ô cam = lệch BOM gốc; chạm Point để chỉnh tay. Kitting VLN dùng BOM này cho mọi PO cùng Model.
  3. Rear + VLĐT: bảng mã × Model Code, PO chỉ nhận đúng BOM của Model Code của nó.
  4. + Model Code: khai Model Code mới, chọn Model, chép BOM từ code khác.
  5. Cập nhật BOM từ file: Tải file mẫu (sheet BOM + dòng mẫu), xóa dòng mẫu, chỉ điền các Model Code cần thêm / cập nhật, rồi nhập. App hiện xem trước; code không có trong file giữ nguyên; tên Model của code đã có không đổi qua file; tối đa 20 code đã có mỗi lần.
  6. Sửa BOM không làm đổi các PO đã bắt đầu kitting.

Kho

  1. Điều phối (màn mở đầu): 4 ô cần xử lý ngay (Line sắp hết việc chưa có PO, Lượt 1 chưa xong, Sẵn sàng giao, Nợ); bảng theo Model (Line · giờ còn việc, sẵn sàng so với min–max, đang làm, chưa làm hôm nay · mai, chưa lập KH 48h, trạng thái Làm ngay / Thiếu tồn / Đủ) — bấm 1 dòng để xem PO; 15 việc tiếp theo có nút VLN / R+VLĐT; Xem tất cả gom theo ngày.
  2. Kit gộp nhiều Model Code: VLN một phiếu chung; phiếu Rear + VLĐT chia khối theo từng code. Giao line được khi có code có Rear — code chưa có Rear ghi nợ, giao bù sau.
  3. VLN / Rear + VLĐT: chạm một PO → tick từng mã (hoặc "Đủ tất cả"), nhập số nếu thiếu → Lưu tạm hoặc Xong. Rear + VLĐT chỉ hiện PO đã bắt đầu VLN.
  4. Quy tắc cấp: Σ Remain PO đã giao − rải chuyền − pending < ngưỡng (mặc định 200) thì Line được cấp tiếp PO / vật liệu. Ví dụ 600 − 400 − 50 = 150 < 200 → được cấp. Từ ngưỡng trở lên là Line còn đủ việc: muốn giao sớm phải gửi duyệt.
  5. Giao line: số to trên mỗi line là con số trên. Bấm Giao → chọn PO (ưu tiên cùng Model) → xem Rear / vật liệu và các mã ghi nợ → xác nhận. PO không có Rear thì không giao được.
  6. Nợ: giao bù từng mã còn thiếu.
  7. ⋮ trên PO → Điều chỉnh kit: chuyển sang PO khác (VLN cùng Model, Rear/VLĐT cùng Model Code), trả kho, hoặc thu hồi từ line (thu hồi hết thì PO được gỡ khỏi line). Lý do chọn từ danh sách.
  8. Lịch sử: báo cáo điều chỉnh theo lý do / kiểu và nhật ký mọi thao tác.
  9. Mọi danh sách / bảng có ô tìm nhanh (gõ không dấu cũng được).

Sản xuất — Line, quản lý sản xuất

  1. Dải Line trên cùng: mỗi Line một ô (Model, số giờ còn việc, số PO Kho sẵn sàng; xanh / vàng / đỏ). Leader được gán Line phụ trách thì mở là vào đúng Line của mình.
  2. Thẻ tổng quan: số còn lại so với ngưỡng, còn khoảng bao nhiêu giờ việc (Remain ÷ UPH Planner khai ở Line & tham số), lúc nào cần PO tiếp, Kho đang có bao nhiêu PO sẵn sàng.
  3. Đang chạy trên Line: tiến độ từng PO và các mã Kho còn nợ. PO tiếp theo: Kho chuẩn bị tới đâu (% VLN, % Rear + VLĐT). PO sắp chạy — Planner chưa lập KH kitting: PO cùng Model gần giờ chạy, chưa gắn Line nào (PO chỉ gắn Line khi Kho giao).
  4. Nút Xin PO tiếp theo / Xin vật liệu ngay tại tab, có kiểm tra ngưỡng.

Line · Duyệt

  1. Cấp vật liệu → + Yêu cầu: chọn Line, xem ngay số còn lại so với ngưỡng; chọn PO tiếp theo hoặc Vật liệu lẻ (mã + số lượng).
  2. Còn < ngưỡng → tự đạt, chờ Kho (PO: Kho giao ở Giao line; vật liệu: Kho bấm Cấp). Còn ≥ ngưỡng → người duyệt Duyệt / Từ chối.
  3. Kho giao PO cho Line chưa đến lúc cấp → hộp thoại hiện "cần duyệt" → nhập lý do → Gửi duyệt.

Báo cáo — mọi tài khoản

  1. Tình hình kitting: chọn khoảng ngày → tỷ lệ đúng kế hoạch, thời gian lập KH → giao, tiến độ theo ngày (Chưa làm / Đang làm / Chờ giao / Đã giao), theo Model, chi tiết từng PO.
  2. An toàn vật liệu: mỗi Line một thước đo số còn lại so với ngưỡng: xanh = đủ việc, vàng = cần cấp và đã có PO sẵn, đỏ = cần cấp nhưng chưa có PO sẵn, chấm PO chờ cấp so với min, số mã nợ.
  3. Ngoại lệ: yêu cầu cấp không đạt quy tắc, duyệt / từ chối, điều chỉnh kit theo lý do.
  4. Tải Excel: 1 file gồm tổng quan, theo ngày, theo Model, chi tiết PO, an toàn Line, ngoại lệ.

Số đỏ / vàng trên tab = việc đang chờ bạn (Kho: PO cần kitting + chờ giao; Duyệt: yêu cầu chờ duyệt; Kho: yêu cầu chờ cấp). Dữ liệu tự làm mới mỗi 45 giây.
